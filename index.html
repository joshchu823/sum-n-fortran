第一題：Fortran 1 加到 N 並編譯執行 20 / 20

指揮 AI 輸出一個能做 1 加到 N 的 Fortran 程式並完成編譯，確認可以成功執行計算並輸出結果。

答案：程式碼（sum_n.f90）

program sum_n
    use iso_fortran_env, only: int64
    implicit none

    integer(int64) :: n, i, total

    total = 0_int64

    print *, 'Please enter N:'
    read *, n

    if (n < 1) then
        print *, 'Error: N must be a positive integer.'
        stop
    end if

    do i = 1, n
        total = total + i
    end do

    print *, '------------------------'
    print *, 'Sum from 1 to N = ', total
    print *, '------------------------'

end program sum_n

過程

  • AI 撰寫程式：使用 int64 避免溢位，並加入 N 小於 1 的輸入檢查。
  • AI 的執行環境沒有 gfortran 且無網路，無法自行編譯，因此改用線上編譯器 OneCompiler（https://onecompiler.com/fortran）。
  • 首次執行因 STDIN 空白導致逾時（Time limit exceeded），原因是程式在等待輸入；在 STDIN 填入 10 後重新執行成功。
